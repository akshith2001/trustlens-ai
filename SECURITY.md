# Security policy

TrustLens is an educational research prototype and must not process real
high-stakes personal data or support operational decisions.

Report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** workflow. Do not include personal data, production credentials
or real applicant records in a report.

The latest commit on `main` is the supported research version. Security fixes
will be documented in the changelog. Because this is not an operational system,
no service-level remediation time is promised.
